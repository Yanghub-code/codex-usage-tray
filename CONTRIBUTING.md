# Contributing

Contributions are welcome.

## Development setup

1. Use Windows 10 or Windows 11 with .NET Framework 4.8.
2. Fork and clone the repository.
3. Create a focused branch.
4. Run `scripts\build.ps1` before submitting a pull request.

## Pull requests

- Keep changes focused and explain the user-visible behavior.
- Do not commit credentials, Codex session data, `status.json`, or machine-specific paths.
- Include a screenshot when changing the taskbar UI.
- Update `CHANGELOG.md` for user-visible changes.
- Confirm that startup, refresh, and exit behavior still work on Windows.

## Issues

Use the provided issue templates. Remove personal paths, account details, tokens, and conversation content from logs before posting.
